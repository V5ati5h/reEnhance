Key Architecture

Built for Reliability & Speed

Traditional App Inventor patching relies on brittle reflection or demands modifying your AIA project. reEnhance fixes the APK at the binary level.

⚡

DEX Bytecode Injection

Directly splices pre-built, verified Google Mobile Ads SDK bytecode into your APK as classesN.dex. No stub errors, no missing classes, zero manual compilation.

🔑

Signature Auto-Matching

Imports your android.keystore or custom keys. reEnhance reads the original certificate SHA-256 and matches it automatically so patched updates install in place.

📦

Binary Manifest Editor

Automatically injects required APPLICATION_ID metadata and permissions (INTERNET, AD_ID) into compiled binary XML without breaking resource tables.

🔄

AAB → APK Converter

Easily convert Play App Bundles into standalone, signed APKs ready for testing on real devices before submitting to Google Play Console.

🎯

Automated Block Detection

Scans your app bytecode to detect only the ad blocks you actually called. Only confirmed ad networks are patched, keeping your app lightweight.

🚀

GitHub In-App Updates

The Manager app checks GitHub Releases for new updates and downloads them in-app, completely independent of the Google Play Store.

Step by Step

From Blocks to Live Ads in 4 Steps

You do not need to install AdMob libraries in App Inventor. Just follow this standard workflow:

1

Import Extension into App Inventor or Kodular

Download dev.v5ati5h.reenhance.aix and import it under Palette > Extension > Import extension. Drag the reEnhance component onto your Screen.

Component reEnhance1 : dev.v5ati5h.reenhance
2

Add Your Ad Blocks

Call any standard ad block inside your event handlers. Multiple banners can coexist in separate arrangements.

when Screen1.Initialize do
  call reEnhance1.ShowBanner(HorizontalArrangement1, "main_banner")
  call reEnhance1.ShowInterstitial("level_complete")
3

Export your APK or AAB

In MIT App Inventor, click Build > Android App (.apk) or Android App Bundle (.aab) to download your built package.

4

Patch & Install with reEnhance Manager

Open reEnhance Manager on your phone > select your APK > review the detected ad networks > tap Build Signed APK. Tap Install to update your app directly!

API Reference

reEnhance Extension Blocks

Clean, streamlined blocks matching standard App Inventor conventions.

Block Name Type Parameters Description
ShowBanner Banner layout: Component, placement: Text Shows a 320x50 inline banner inside a Horizontal or Vertical Arrangement.
ShowLargeBanner 320x100 layout: Component, placement: Text Shows a 320x100 large banner inside a visible arrangement.
ShowMrec 300x250 layout: Component, placement: Text Shows a 300x250 Medium Rectangle (MREC) ad.
ShowInterstitial Fullscreen placement: Text Loads and displays a fullscreen interstitial transition ad.
ShowRewarded Rewarded placement: Text Shows a rewarded video ad and triggers the UserEarnedReward event.
ShowAppOpen App Open placement: Text Shows a fullscreen App Open ad when the application is brought to foreground.
HideAds Control none Dismisses all active inline banner/MREC ads and closes overlay dialogs.
Help & Answers

Frequently Asked Questions

Quick solutions to common questions and edge cases.

Why did Android say "Package conflicts with an existing package"?
Android requires updates to be signed with the identical key as the installed app. Export your keystore from App Inventor via Projects > Export Keystore (password is android, alias androidkey). In reEnhance Manager, import it under the Signing Keys tab. reEnhance will automatically match the key and sign your patched apps so they update seamlessly!
Do I need to manually configure AdMob dependencies in App Inventor?
No! The patcher automatically injects the official Google Mobile Ads SDK bytecode directly into the APK as a secondary DEX file (multidex) along with all required manifest entries and permissions.
Can I test without entering real AdMob unit IDs?
Yes! Enable Test Mode in the reEnhance Manager. It automatically seeds official Google sample ad units and test Application IDs, allowing safe end-to-end testing without risking your live AdMob account.
Where can I manage and clear cached SDK DEX files?
In reEnhance Manager, switch to the Tools tab. Under the SDK Cache card, you can view the storage used by cached DEX bundles and tap Clear AdMob cache or Clear all to force fresh extraction from app assets.
